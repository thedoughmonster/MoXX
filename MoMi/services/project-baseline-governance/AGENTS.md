# Project Baseline Governance Rules

- Own immutable material decision history and bootstrap reconciliation only.
- Admit scope, contract, data, security, operations, rollout, debt, supersession,
  and governance decisions; exclude routine mechanics.
- Append lifecycle, evidence, and references through the owned routines.
- Never update, delete, or truncate ledger history.
- Correct a decision only through a superseding or revoking event.
- Keep the schema private and grant no Data API role access.
- Never promote or mutate production without explicit owner approval.
